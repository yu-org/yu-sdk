# yu-sdk/rust

Rust SDK for interacting with a [yu](https://github.com/yu-org/yu) blockchain node.

## Features

- **Writing**: send signed transactions to the chain (`/api/writing`)
- **Reading**: query chain state (`/api/reading`)
- **Event subscription**: receive receipts via WebSocket (`/subscribe/results`)
- **Key types**: Ed25519 (via `ed25519-dalek`), Secp256k1 (via `k256`)

## Usage

```rust
use yu_sdk::{YuClient, KeyPair};
use std::collections::HashMap;

#[tokio::main]
async fn main() {
    let kp = KeyPair::generate_ed25519();
    let my_addr = kp.address();

    let client = YuClient::new("http://localhost:7999", "ws://localhost:8999")
        .with_keypair(kp);

    // Writing call
    client.write_chain(
        "asset", "CreateAccount",
        &serde_json::json!({ "amount": 500u64 }),
        0, 0,
    ).await.unwrap();

    // Reading call
    let mut params = HashMap::new();
    params.insert("account", my_addr.as_str());
    let resp = client.read_chain("asset", "QueryBalance", &params).await.unwrap();
    println!("balance: {}", resp["amount"]);

    // Subscribe to events
    let (mut rx, _handle) = client.subscribe_events().await.unwrap();
    while let Some(receipt) = rx.recv().await {
        println!("receipt: {:?}", receipt);
    }
}
```

## Key types

```rust
use yu_sdk::KeyPair;

// Ed25519
let kp = KeyPair::generate_ed25519();
let kp = KeyPair::from_ed25519_bytes(&seed);            // 32-byte seed

// Secp256k1
let kp = KeyPair::generate_secp256k1();
let kp = KeyPair::from_secp256k1_bytes(&privkey)?;      // raw 32-byte key
let kp = KeyPair::from_secp256k1_secret(b"my secret");  // == yu's GenSecpKeyWithSecret

println!("{} {} {}", kp.key_type.as_str(), kp.address(), kp.pubkey_with_type());
```

| Key type  | Type index | Public key          | Address                            |
|-----------|------------|---------------------|------------------------------------|
| Ed25519   | `0x32`     | 32 bytes            | `SHA256(pubkey)[..20]`             |
| Secp256k1 | `0x33`     | 33 bytes compressed | `RIPEMD160(SHA256(pubkey))`        |

> Note: yu's own `SecpPubkey.BytesWithType()` prepends `Sr25519Idx` (`0x31`),
> which its `PubKeyFromBytes` would decode back as an sr25519 key. This SDK
> emits `Secp256k1Idx` (`0x33`) so the node decodes it as secp256k1.

## Signing

Writing transactions are signed using:

1. JSON-serialize the `WrCall` struct
2. Take the last 32 bytes (`BytesToHash`)
3. Sign that hash with the key pair:
   - **Ed25519** — sign the hash directly with `ed25519-dalek` (64-byte signature)
   - **Secp256k1** — ECDSA over `SHA256(hash)`, serialized as 64-byte `R || S`
     in lower-S form, matching tendermint's `PrivKey.Sign`

The secp256k1 key derivation, address and signature bytes are verified against
vectors generated by yu itself in `tests/keypair_test.rs`.

## Running Tests

Start the test chain first:

```bash
cd ../testchain
go mod tidy
go run main.go
```

Then in a separate terminal:

```bash
cd rust
cargo test -- --nocapture
```

The key pair tests in `tests/keypair_test.rs` need no chain and can be run on
their own:

```bash
cargo test --test keypair_test
```
